# Generate deterministic model inputs.

This function generates the deterministic model inputs for the example
health economic model developed to test the functionalities of the
package.

## Usage

``` r
generate_det_inputs()
```

## Value

A list. A description of the inputs parameters is available in the
documentation of the
[`df_pa`](https://xa4p.github.io/pacheck/reference/df_pa.md) dataframe.

## Examples

``` r
# Generating deterministic model inputs and storing them in an object.
l_inputs_det <- generate_det_inputs()
```
